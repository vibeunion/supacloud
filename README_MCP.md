# SupaCloud MCP (Model Context Protocol) 使用指南

SupaCloud 默认集成了一个基于 Supabase Edge Functions 的 MCP 服务器。这允许 AI 助手（如 Claude Desktop, Cursor）直接调用您的私有云工具和数据。

## 1. 快速配置

要让您的 AI 客户端连接到 SupaCloud MCP，您需要修改客户端的配置文件。

### 客户端配置示例 (Claude Desktop / Cursor)

请将以下内容添加到您的 MCP 配置文件中（通常位于 `%APPDATA%\Claude\claude_desktop_config.json` 或项目根目录）：

```json
{
  "mcpServers": {
    "supacloud": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-proxy",
        "https://YOUR_DOMAIN/functions/v1/mcp",
        "--header",
        "Authorization: Bearer YOUR_ANON_KEY"
      ]
    }
  }
}
```

*   **YOUR_DOMAIN**: 替换为您的 SupaCloud 对外域名（例如 `supa.example.com`）。
*   **YOUR_ANON_KEY**: 替换为您的 Supabase `ANON_KEY`。您可以在服务器上的 `/etc/supabase/jwt-keys.env` 文件中查看此密钥。

## 2. 核心组件说明

### 2.1 云端 MCP 函数 (Server)
安装脚本会自动在您的云平台上部署一个 MCP Edge Function。
*   **源码位置**: `~/pigsty/app/supabase/volumes/functions/mcp/index.ts`
*   **运行时**: 默认 Deno（可切换至 Bun）。
*   **传输协议**: SSE (Server-Sent Events) 通过 Hono 框架实现。

### 2.2 本地代理 (Proxy)
由于大多数 AI 客户端（如 Claude Desktop）期望使用 `stdio` 传输模式，而 Edge Function 使用 `HTTP/SSE`，因此我们需要使用 `mcp-proxy` 进行桥接。

## 3. 开发引导：如何添加自定义工具

您可以随时修改云端的 MCP 函数来增加新功能。

1.  **编辑文件**: `vi ~/pigsty/app/supabase/volumes/functions/mcp/index.ts`
2.  **添加工具**:
    ```typescript
    server.registerTool(
      'my_new_tool',
      {
        title: '我的新工具',
        description: '做一些很酷的事情',
        inputSchema: { param: z.string() },
      },
      ({ param }) => ({
        content: [{ type: 'text', text: `处理结果: ${param}` }],
      })
    )
    ```
3.  **保存生效**: Supabase Edge Runtime 会检测文件变化并自动热重载，无需重启容器。

## 4. 常见问题排查 (Troubleshooting)

### 4.1 访问报错 404
*   确保您的域名解析正确。
*   确认安装脚本中的 `install_enhanced_gateway` (OpenResty) 已正确处理反向代理。
*   检查 Edge Function 是否已启动: `docker ps | grep edge-runtime`。

### 4.2 鉴权失败 (401 Unauthorized)
*   确保 `Authorization` 头包含 `Bearer ` 前缀。
*   检查 `ANON_KEY` 是否过期。如果重新运行了安装脚本并刷新了 JWT Secret，旧 Key 将失效。

### 4.3 跨域或代理失败
*   在本地尝试运行命令进行调试:
    `curl -I https://YOUR_DOMAIN/functions/v1/mcp`
*   如果返回 `405 Method Not Allowed` 是正常的（因为 MCP 期待 POST 请求），但如果返回 `502` 则是网关配置问题。
